# MyHome («Мой дом»)

Android-приложение с игровыми экранами и мини-играми (миссии, питомец, награды), управляемое через сигнал с устройства / эмулятора сигнала.

> Проект на Kotlin, сборка через Gradle (Kotlin DSL).

## Требования

| Что | Версия |
|-----|--------|
| Android Studio | Последняя стабильная (Koala и новее) |
| JDK | 17 (встроенный в Android Studio подходит) |
| Android SDK | Platform, указанная в `compileSdk` в `app/build.gradle.kts` |
| Git | любая актуальная |

Интернет нужен при первой сборке — Gradle скачает зависимости.

## Быстрый старт

1. Клонируйте репозиторий:

   ```bash
   git clone https://git.codenrock.com/codenrock/motorika-kod-dvizheniya/robolapka/igra-trenazher
   cd igra-trenazher
   ```

2. Откройте папку проекта в Android Studio: **File → Open** и выберите папку `MyHome` (ту, где лежит `settings.gradle.kts`).

3. Дождитесь окончания **Gradle Sync** (индикатор внизу справа). Если Android Studio предложит установить недостающие компоненты SDK — согласитесь.

4. Выберите конфигурацию запуска **app** и устройство (эмулятор или телефон) в верхней панели.

5. Нажмите **Run ▶** (`Shift + F10`).

## Запуск на эмуляторе Android

1. **Tools → Device Manager → Create Device**.
2. Выберите профиль устройства (например, Pixel 6) и образ системы (рекомендуется API 34 или тот, что указан в `minSdk`/`targetSdk` проекта).
3. Запустите эмулятор кнопкой ▶ в Device Manager.
4. Выберите его в списке устройств и нажмите **Run ▶**.

## Запуск на реальном телефоне

1. На телефоне включите **Режим разработчика**: *Настройки → О телефоне →* 7 раз нажмите на «Номер сборки».
2. Включите **Отладку по USB** в *Настройки → Для разработчиков*.
3. Подключите телефон к компьютеру по USB и разрешите отладку на запрос.
4. Выберите телефон в списке устройств в Android Studio и нажмите **Run ▶**.

## Сборка из командной строки

Из корня проекта:

**Linux / macOS**

```bash
chmod +x gradlew
./gradlew assembleDebug
```

**Windows**

```bat
gradlew.bat assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённое устройство:

```bash
./gradlew installDebug
```

Запуск тестов (если они есть в проекте):

```bash
./gradlew test
```

## Эмулятор сигнала

Приложение получает управляющий сигнал от устройства. Для разработки без реального устройства используется эмулятор сигнала.

- Как проходит калибровка: калибровка выполняется один раз, при последующих запусках происходит разминка. Если при разминке сигнал сильно отличается от первоначальной клибровки, то происходит перенаправление на калибровку.
- Прогресс игры (пройденные миссии, питомец) сохраняется между запусками.
